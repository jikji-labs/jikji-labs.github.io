실행에서 연구 근거까지, 연결된 상태

상태·기억·도구 결과·실험·주장을 처음부터 그래프 식별자와 출처를 가진 엔터티로 설계합니다.

SQL 정본, 권한 있는 지식 뷰

타입이 있는 SQL 행과 quads가 정본입니다. 상태·이벤트·그래프·outbox를 같은 트랜잭션으로 기록하고 지식 엔진은 권한 필터된 읽기 projection을 사용하도록 설계합니다. 지연된 projection을 최신 권한 결정에 사용하지 않습니다.

과학적 주장의 생애

가설 → 실험·프로토콜 → 데이터·산출물 → 검증·독립 리뷰 → 지지·반박·논쟁 상태를 연결합니다. 기억에는 근거·유효 기간·검증 상태를 두며 모델 제안은 미검증 상태로 시작합니다.

스키마 검증과 진실성 구분

SHACL·provenance와 bounded query는 기술 검증 대상입니다. 스키마가 맞는다고 과학적 참이 되는 것은 아니며 실험 oracle과 리뷰가 필요합니다. 지식 엔진 통합 API·자원 비용은 기술 실험에서 확인해야 합니다.
