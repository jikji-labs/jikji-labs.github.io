작은 코어, 명확한 경계

Rust 코어는 실행·권한·예산·상태 전이의 불변식을 맡고, Lua 내장 확장과 격리된 Python 플러그인이 통합을 담당하는 구상입니다. 원본 보존·출처와 GPL 라이선스 의무를 유지하는 계약 재구현을 계획합니다. 단일 바이너리를 목표로 하되 보조 프로세스의 비용도 별도로 계산합니다.

근거가 먼저

모델의 완료 선언이나 평판만으로 연구 결과를 확정하지 않습니다. 실험·검증자·데이터 버전·영수증을 연결하고 상충하는 주장을 함께 보존합니다.

점진적 이전

기존 시스템과 읽기 전용 비교로 시작해 선택적 도입과 롤백 훈련을 거칩니다. 한 번에 전체 시스템을 교체하지 않으며, 현재 페이지는 제품 출시나 운영 지원을 뜻하지 않습니다.
