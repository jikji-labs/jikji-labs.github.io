설계에서 검증으로, 단계별로

현재는 G0 설계 검토 단계입니다. 아래 단계는 계획이며 구현 완료·성능 달성·배포 완료를 뜻하지 않습니다.

G0 → G2 · 설계와 로컬 기반

G0: 원본·라이선스 조사, R1~R20 요구와 ADR·위협 모델·설계 검토. G1: 모델 이벤트 계약·지식 엔진·DB·OS sandbox 기술 실험과 자원 기준 측정. G2: 로컬 루프·도구·영수증·그래프와 두 DB의 계약 검증. 구현 시작 전 설계 검토와 승인 절차가 남아 있습니다.

G3 → G6 · 분산 검증과 점진 도입

G3: 서버·워커·API·위임·대시보드와 장애·취소·권한 시험. G4: 실제 모델 paired benchmark와 독립 품질 판정. G5: 선택적 도입·복구 훈련. G6: 근거와 관측을 바탕으로 소비자별 기본값 전환. 각 단계는 검증 결과와 별도 전환 판단이 필요합니다.

진행 로그 · 2026-10-18

설계 문서 01~10과 R1~R20을 바탕으로 공개 가능한 설계 요약을 작성했습니다. 전체 설계 검토는 진행 중이며 성능 실측이나 production build 통과는 주장하지 않습니다. 다음 갱신은 검토 결론·기술 실험·구현 시험의 실제 근거가 생긴 뒤 기록합니다.
