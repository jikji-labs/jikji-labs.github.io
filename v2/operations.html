같은 상태를 보는 사람과 에이전트

한국어 대시보드와 에이전트 API가 같은 정책·상태·세대를 보며 실시간 관측과 근거 있는 결재를 지원하도록 설계합니다.

대시보드·요약·관측

실행·위임 트리·작업 검토·예약 일정·잔량의 갱신 시각·예산·메시지 지연·projection 지연을 권한 안에서 보여주는 구상입니다. Prometheus·OpenTelemetry 연계와 기존 모니터링 adapter는 계획이며 비공개 인증을 기본으로 합니다. 요약은 기간·기준 시각·결측을 표시합니다.

상신·승인·실행 연결

승인은 인증된 결정자와 정확한 계획 digest·대상 버전·권한·예산·만료에 묶습니다. 계획 변경이나 재사용은 기존 승인을 무효화합니다. 모델 자기 승인이나 외부 댓글만으로 실행 권한을 만들지 않습니다. UI 버튼 숨김은 보안 경계가 아닙니다.

예약 작업과 안전한 변경

cron·interval·one-shot·event·webhook 등록에는 소유자·권한·예산·버전을 둡니다. 발생 건 중복 제거와 누락 실행 정책을 명시합니다. 기존 결재 기록은 이력으로만 가져오고 실행 grant로 바꾸지 않으며, 기능별 shadow 비교 후 점진적으로 이전합니다.
