Design stage — before implementation

One state for people and agents

A Korean-first dashboard and agent APIs are designed to share policy, state and generations, with real-time observation and evidence-bound approvals.

Dashboard, summaries and telemetry

Proposed views cover runs, delegation trees, reviews, schedules, quota age, budgets, message lag and projection lag within authorized scopes. Prometheus, OpenTelemetry and monitoring adapters are planned and private by default. Summaries identify periods, watermarks and missing data.

Bind proposals, approvals and execution

Approval binds an authenticated decision maker to an exact plan digest, target revision, scope, budget and expiry. Plan changes and replay invalidate grants. Model self-approval and external comments alone cannot create execution authority. Hiding a UI button is not authorization.

Scheduled work and safe changes

Cron, interval, one-shot, event and webhook jobs carry owners, scopes, budgets and revisions. Occurrence deduplication and misfire policies are explicit. Imported approvals remain historical records, not live grants. Adoption follows per-feature shadow comparisons.
