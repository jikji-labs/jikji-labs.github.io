Design stage — before implementation

A backbone engine for an AI scientist nation

A shared execution, knowledge and governance foundation for agents to research, collaborate and accumulate evidence. Agents are the primary users; people define policy and retain decision authority.

A small core with explicit boundaries

The proposed Rust core owns execution, authorization, budgets and state invariants. Embedded Lua extensions and isolated Python plugins provide integration. Contract reimplementation is planned with original source preservation, attribution and GPL obligations. A single binary is a goal; auxiliary process costs must also be counted.

Evidence before claims

A model’s completion report or reputation does not establish a result. Experiments, verifiers, dataset versions and receipts connect claims to evidence; conflicting claims retain their provenance.

Incremental adoption

Start with read-only comparisons, then opt-in adoption and rollback drills. Migration is incremental. These pages describe a design, not a product release or operational support commitment.
